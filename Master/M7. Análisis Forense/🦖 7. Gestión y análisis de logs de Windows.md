
**Archivos de Registro:** También conocidos como archivos de _log_, consisten en ficheros o archivos que almacenan información sobre el sistema y sus últimas modificaciones, incluyendo especificaciones sobre los servicios y aplicaciones ejecutados, y datos sobre el _kernel_ y sobre la BIOS, entre otros aspectos de suma trascendencia.

Para los analistas forenses, los _**logs**_ son un **elemento central** a la hora de obtener evidencias. Estos archivos pueden proporcionar información tan importante como las acciones que se han llevado a cabo en el sistema, listas de errores o eliminaciones de _software_ malintencionado, pasando por listados detallados de actualizaciones.

**Volume Shadow Copy (VSC):** Es el servicio que permite crear copias de seguridad del equipo cada cierto tiempo y, de ese modo, restaurar el sistema en caso de fallo general o de que el usuario así lo decida. En Windows, se le conoce como “punto de restauración del sistema”.

Usa herramientas como:

- **Vssadmin:**
	- Con ella se consigue visualizar las copias de los volúmenes actuales, así como todos los proveedores y creadores de instantáneas que se hubiesen instalado. El comando _vssadmin list shadows_ muestra las instantáneas realizadas.
- **MkLink:**
	- Se emplea para crear un enlace simbólico a un directorio o archivo, o bien crear un enlace a una unión de directorios.
- **Otras:**
	- Existen otras herramientas con las cuales se pueden obtener las mismas prestaciones mencionadas anteriormente, como **The Sleuth Kit (Autopsy)** o **VSC Toolset.**
