# ⚔️ 1.1 Auditoría de seguridad vs Escaneo de vulnerabilidades

**Auditoría de seguridad:** *Metodología sistemática que verifica de forma efectiva la seguridad de una organización.*

**Escaneo de vulnerabilidades:** *Prueba reducida y concreta cuyo objetivo único es la identificación de vulnerabilidades.*

La diferencia se basa en que en una **auditoría de seguridad de Hacking Ético** buscamos simular un ataque informático real con el menor numero de restricciones posibles, siendo más caro para la empresa y costoso en el tiempo, pero con mejores resultados que un **escaneo de vulnerabilidades.**

# 🛡️ 1.2 Marcos de auditorías de seguridad

Existen auditorías de seguridad de distintos tipos como, por ejemplo, infraestructura, aplicaciones web o aplicaciones móviles.

Cada tipo de auditoría implica llevar a cabo unas acciones específicas dependiendo de lo que se esté auditando, es por ello por lo que existen distintos marcos que se pueden tomar.

<b>Los marcos de seguridad más populares son:</b>

## 🎛️ 1.2.1 Penetration testing execution standard (PTES)

**Define paso a paso cómo realizar un test de penetración profesional,**  incluye interacción directa y acordada entre el **pentester** y el **responsible** del sistema.

## 🔭 1.2.2 Open source security testing methodology manual (OSSTMM)

Metodología abierta y genérica para **evaluar seguridad** en **redes, personas, procesos y sistemas,** analiza múltiples áreas de seguridad de la organización, no solo tecnología.

## 🧨 1.2.3 Penetration testing framework

Marco centrado exclusivamente en test de penetración que proporciona **guías prácticas** para **planificar, ejecutar y documentar ataques controlados.**

## 🐞 1.2.4 OWASP testing framework

Metodología orientada a **pruebas de seguridad** en **aplicaciones web** la cual describe técnicas específicas para detectar vulnerabilidades en **software online.**

## 📏 1.2.5 NIST Technical Guide Information Security Testing and Assessment

Contiene las pautas que hay que seguir durante el **proceso** de **test de penetración**, desde **la planificación** hasta el **reporte final.**

# 🕹️ 1.5 Prácticas técnicas de hacking: juegos

Existen diferentes **juegos** para practicar estas técnicas como *war games* o *capture the flag. (CTF)*

Existen multitud en **portales web, servidores remotos o máquinas virtuales.**

Las Capture the Flag, son competiciones organizadas en Internet y en los congresos de seguridad, donde, **de manera indivual o colectiva,** se ha de cumplir unos objetivos siguiendo ciertas reglas y en el tiempo establecido.

dentro de estas pruebas se encuentran **ataques web, ingeniería inversa, análisis de tráfico en red, explotación de vulnerabilidades, análisis de cifrado, desarrollo de herramientas...**

Algunos de estos juegos son:
- Hack The Box (HTB)
- VulnHub
- OverTheWire
- NetWars
- PentesterLabs
- Hacker Experience
- Hack this Site
- Hacking Labs
- Smash the Attack

El nivel de sofisticación de estos juegos es muy variado: desde pruebas muy simples realizando un ataque web de cross-site scripting (XSS) hasta analizar un binario desconocido para explotar una vulnerabilidad.
