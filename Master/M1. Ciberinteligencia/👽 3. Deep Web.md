# 🧅 3.1 The Onion Router (TOR)

<div style="display: flex; justify-content: space-between; align-items: center;">
  <img src="TOR.png" alt="Imagen 1" style="width: 100%; border-radius: 8px;">
</div>

**TOR** es un proyecto *open source* cuyo objetivo es **servir de red de comunicaciones** apoyándose en la ya conocida Internet. Su principal ventaja es el **anonimato,** es decir, **el usuario no expone la dirección.**

<div style="border:1px solid #000; border-radius:10px; padding:12px; box-sizing:border-box;"><div style="display: flex; justify-content: space-between; align-items: center;">
  <img src="NodosTOR.png" alt="Imagen 1" style="width: 100%; border-radius: 8px;">
</div>
</div>

La comunicación por Tor se realiza mediante **saltos por nodos Tor,** estos nodos encaminan el tráfico de un punto a otro, tal y como lo hacen los routers habituales.

Estos datos **viajan cifrados** a través de todos los saltos de la comunicación, exceptuando el punto entre el **último salto** y el **destino final.**

Las rutas se generan de **forma aleatoria,** por lo que a un mismo usuario se le pueden asignar **distintas rutas** para conectar con el **mismo servidor.**

**los sitios web alojados bajo este proyecto se reconocen fácilmente mediante el seudo-TLD que utilizan ".onion"

# 🕶️ 3.2 Foros Underground

Son **páginas web** alojadas dentro de la Deep Web compuestas por cientos de usuarios para comprar y vender **productos ilegales.**

Dentro de nuestro campo de **ciberseguridad** hablaremos de que se realiza la compra-venta de **ciberamenazas** ***(phising, malware, dominios vulnerados...)***

**Los servicios** se proporcionan mediante un determinado usuario al que se conoce como **actor** que puede ser una única persona o una organización, y las **ventas** se realiza mediante **publicaciones** en la **comunidad underground** en las cuales se detalla el servicio que se esta vendiendo y su coste.

Dentro de este sitio apenas existen **estafas,** no suelen ser fraudes para ganar credibilidad.
